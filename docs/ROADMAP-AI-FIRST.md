# 小斐 AI：先完善通用 AI 客户端（2026-10-29）

## 目标

面向 iPhone 4S / iOS 8.4.1，做一款 API 驱动的中文 AI 客户端。完成聊天与 AI 内容能力后，再考虑手机系统操作。**不在仓库中提交密钥。**

## 功能优先级

| 优先级 | 功能 | 验收标准 |
|---|---|---|
| P0 | 模型库 | 添加、编辑、删除、切换；多厂商；同厂商多模型；密钥可更新；失败显示实际错误 |
| P0 | 文本聊天 | 真实 API 返回、连续多轮、停止回答、错误详情、重试 |
| P0 | 会话管理 | 本地持久化、新建、历史、删除、恢复 |
| P1 | 流式回答 | SSE 增量显示，不让界面卡死 |
| P1 | 图片输入 | 从相册或相机选图；显示支持视觉的模型；上传尺寸限制 |
| P1 | 中文语音 | STT + TTS 独立设置；录音与播报 |
| P1 | 联网 | 官方 web_search 或可配置搜索 API；标注来源；无搜索时提示 |
| P2 | 图片生成 | 单独图像 API；相册保存 |
| P2 | 文档 | 先 TXT/文本，再 PDF 解析；长文按能力分块 |
| P2 | 推理参数 | 按模型能力显示深度思考、温度、上下文 |
| P3 | 高级工具/手机操作 | 授权与审计后逐步加入 |

## 重要原则

1. Chat Completions 兼容的是文字/部分多模态结构；**图片生成、音频和搜索不保证同一个接口提供**。
2. 功能按钮应当根据配置的模型能力显示或禁用，不允许假装支持。
3. 旧版 iOS 8 HTTPS/TLS 可能与现代厂商不兼容。原生直连先实测；必要时增加部署在云端的兼容网关，不能要求 Windows 一直开机。
4. API Key 尽量用钥匙串；失败展示 OSStatus 错误码，用户可主动选择权限受限的本地文件兼容保存，并理解越狱设备风险。
5. 旧版 rootful DEB 必须为 armv7，安装包 gzip 格式，并保留 uicache/postinst 兼容逻辑。
6. 每个版本至少验证：安装启动、增删改选模型、保存密钥、真实文字回复、重开后的历史保留和网络错误提示。
